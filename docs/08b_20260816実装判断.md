# 99L Mission Board 2026-08-16 実装判断

> **2026-08-16更新:** パラシュートのOpen/Close、STS3215 Hold、NVS、readiness、廃止commandについては[[08e_20260816_パラシュート簡素化|08e パラシュート簡素化仕様]]を優先する。本書に残る絶対角endpoint、NVS、Free、Open retryの旧記述は当該範囲では廃止。


本書は2026-08-16時点でoperatorが明示的に確定した実装判断を記録する。既存の安全条件、構造limit、MotorProfile qualification、simulation gateを緩和するものではない。

## 1. Fin zero / CommandReceive操作

- `FinZeroConfigured`はboot時の最初のAS5047D sampleから自動生成しない。
- `SetFinZero`が正常完了した場合だけ、現在のmotor-side AS5047D位置をencoder zero referenceとして`FinZeroConfigured=true`にする。
- `SetFinZero`と`StartFinZeroHold`は別操作のままとする。
- `FinFree`、`SetFinZero`、`StartFinZeroHold`、`FinMoveRelative`をCommandReceiveの実commandとして実装する。
- `FinMoveRelative`は飛行用`FinSoftwareLimits`を越えるtargetを拒否し、timeout時は駆動継続せず安全側へ停止する。

## 2. PreflightCalibration / SSC zero

- SSC差圧zeroはCommandReceive中に常時rolling更新しない。
- `RunPreflightCalibration`開始時に旧SSC zeroをinvalid化し、そのattempt中に取得したzeroだけを採用する。
- calibration完了後はzeroをfreezeし、次のcalibration attemptで再取得する。
- gyro bias / gravity / SSC zeroは最新attemptの結果だけを使用し、失敗項目を旧値へrollbackしない。

## 3. MotorProfile qualification

- MotorProfileのparameterが数値として設定済みであることとflight qualification済みであることを別に扱う。
- 現FlightMotorAはparameter候補を保持するが、実機qualification完了までは`MotorProfileValid=false`とする。
- 通常`StartSequence`はこのgateを通さない。`ForceStartSequence`は既存仕様どおり初期セットアップgateだけをbypassし、qualification済みへ偽装しない。

## 4. PWM

- TB67H450FNG PWM carrierは**30 kHz**を維持する。
- production firmwareの追加software duty clampは**100%**とし、15%固定clampは使用しない。
- 100% duty許可は常時100%を出す意味ではない。`TorqueMapper`のMotorProfile current/torque limit、fin software angle limit、NaN/invalid時Brake等の既存安全条件は維持する。
- characterization専用buildの試験campaign limitはproduction duty上限とは別に扱う。

## 5. Gain table

- 速度別gain tableの最終値はsimulation未実施のため、この変更では更新しない。
- 現在のprovisional tableをflight-qualified値とは扱わず、simulation完了後に別変更として反映する。

## 6. Flash raw export

Internal Flashのraw export/erase条件は[[08a_飛行ログ実装仮定#MISSION-LOG-006 ExportFlashLogToSdAndErase raw export|08aのMISSION-LOG-006]]に従う。
