# 99L Mission Board 量子化・エラーコード詳細

## 1. 位置付け

本書は[[04_通信仕様|通信仕様]]で使用する量子化、reserved code、Status bitの詳細を定義する。Mission Board側でsemantic value/errorを本書のraw値へencodeし、通信基板はMission由来raw値を再量子化しない。

数値fieldで現在値がvalidな場合、一時errorが発生したという理由だけでerror codeへ置換せず、Status/MissionEvent等のinterval eventを併用する。

## 2. Flight Status 16 bit

- bit0 LPS liftoff detected
- bit1 ICM liftoff detected
- bit2 ICM42688 alive
- bit3 STS3215 alive
- bit4 Roll Control active
- bit5 Battery1=logic source present
- bit6 Battery2=motor source present
- bit7 通信基板microSD healthy
- bit8 Mission↔通信基板CAN healthy
- bit9 前回LoRa FlightTelemetry以降のICM data loss/error
- bit10 AS5047D error
- bit11 AirData error
- bit12 fin motor saturation
- bit13 fin Brake
- bit14 Mission reset/recovery event
- bit15 Control re-entry inhibited

`fin_control_disabled`の原因はMissionEvent `FinControlDisabledByGround`とbit13/15で追跡する。

## 3. roll `φ`

16 bit two's complement、0.5 deg/LSB、unwrapped。離床時刻を0 radとする`roll_estimate_liftoff_relative_unwrapped_rad`を表し、Control referenceを差し引かない。`0x8000..0x800F`を予約する。

reserved codeを除くnumeric raw rangeは-32752..32767 count、物理rangeは-16376.0..+16383.5 degである。負値の`0x8000..0x800F`（-32768..-32753 count）は下記error専用とし、numericにdecodeしない。

| input | count | 表現可否 |
|---:|---:|---|
| +380 deg | 760 | 可 |
| +720 deg | 1440 | 可 |
| -720 deg | -1440 | 可 |

したがって今回必要な+380 degと±720 degは現行bit幅/LSBで正確に表現できる。numeric range外は`800A SATURATED_OR_OUT_OF_RANGE`とし、端点値へclampせず、360 deg単位でwrapせず、two's-complement overflowを起こさない。Mission SDはwire量子化前のfull-precision unwrapped値を保持する。compact telemetryでrange超過した区間の正確値はMission SDが無ければ復元できないため、Ground/log parserはerror codeを数値として接続せず欠測理由を保持する。

- `8000` UNAVAILABLE
- `8001` NOT_INITIALIZED
- `8002` SPI_TIMEOUT
- `8003` SPI_ERROR
- `8004` STALE_OR_NO_NEW_SAMPLE
- `8005` FIFO_FULL
- `8006` FIFO_LOST_PACKET
- `8007` FIFO_FORMAT_FAULT
- `8008` SAMPLE_INVALID
- `8009` ODR_CHANGED
- `800A` SATURATED_OR_OUT_OF_RANGE
- `800B` TIMESTAMP_INVALID
- `800C` ATTITUDE_ESTIMATOR_INVALID
- `800D` RESET_INVALIDATED
- `800E` INTERNAL_ERROR
- `800F` UNKNOWN

単一sample欠落を補間して姿勢validを維持した場合はnumeric rollを送信しつつFlight Status bit9を立てる。許容欠落数は`TODO(SIMULATION)`。

### 3.1. version 2 Control reference/deviation

`ControlRollTelemetryV2 0x10A`および`A7 ControlRollTelemetryV2`の`control_roll_reference_unwrapped`と`roll_deviation_unwrapped`は本節と同じ16 bit two's complement、0.5 deg/LSB、numeric/error rangeを使用する。これらは互いに別fieldであり、既存v1 roll fieldを再解釈しない。

- reference未capture/invalid: `8000 UNAVAILABLE`
- resetによるinvalid: `800D RESET_INVALIDATED`
- numeric range超過: `800A SATURATED_OR_OUT_OF_RANGE`
- その他の姿勢quality error: 本節の対応code

deviationのencoderは必ずunwrapped differenceを直接量子化する。`wrapToPi`、`mod`、最短路化でrange内へ押し込むことを禁止する。reference=0、current=+380 degではdeviation raw=760とし、-20 deg/raw=-40に置換しない。

## 4. roll rate `φdot`

16 bit two's complement、0.1 deg/s/LSB。`0x8000..0x800F`はrollと同じICM系error codeを使用する。

## 5. 3D表示用tilt

### 5.1. tilt magnitude

7 bit。raw0..120を正常値とし、`tilt_deg = raw * 0.75`で0..90 degを表現する。

- 121 UNAVAILABLE
- 122 NOT_INITIALIZED
- 123 STALE
- 124 ESTIMATOR_INVALID
- 125 RESET_INVALIDATED
- 126 OUT_OF_RANGE
- 127 UNKNOWN

### 5.2. tilt direction

9 bit。真北=0 deg、東回り正。raw0..359を0..359 degとして使用し、360..511をreservedとする。

`tilt magnitude`がerror codeまたは0 degの場合はdirectionを姿勢判断へ使用しない。

## 6. fin angle `θ`

8 bit。raw0..240を正常値とし、`theta_deg = -15 + raw * 0.125`。

- 241 NOT_INITIALIZED
- 242 SPI_TIMEOUT
- 243 SPI_ERROR
- 244 RESPONSE_PARITY_ERROR
- 245 SENSOR_PARITY_ERROR
- 246 INVALID_COMMAND
- 247 FRAMING_ERROR
- 248 PIPELINE_STATE_ERROR
- 249 STALE
- 250 UNWRAP_AMBIGUOUS
- 251 ZERO_NOT_CONFIGURED
- 252 RESET_INVALIDATED
- 253 OUTPUT_ANGLE_INVALID
- 254 OUT_OF_MECHANICAL_RANGE
- 255 INTERNAL_OR_UNKNOWN

## 7. fin rate `θdot`

16 bit two's complement、0.02 deg/s/LSB。`0x8000..0x800F`をerror領域とする。

- `8000` UNAVAILABLE
- `8001` SOURCE_ANGLE_ERROR
- `8002` STALE
- `8003` NOT_ENOUGH_SAMPLES
- `8004` UNWRAP_AMBIGUOUS
- `8005` TIMESTAMP_INVALID
- `8006` ESTIMATOR_NOT_READY
- `8007` ESTIMATOR_NUMERIC_ERROR
- `8008` OUT_OF_RANGE
- `8009` RESET_INVALIDATED
- `800A..800F` reserved

Fin Velocity Estimatorの方式はwire形式に影響しない。現在はquadratic regression N=3を初期production candidateとし、実機noiseを用いたalpha-betaとの再比較後に最終決定する。

## 8. requested output torque

12 bit two's complement。`0x800..0x80F`をerror領域とし、正常countは-2032..2047を使用する。

- `800` UNAVAILABLE
- `801` CONTROLLER_INPUT_INVALID
- `802` CONTROLLER_NUMERIC_ERROR
- `803` RESET_INVALIDATED
- `804` LIMIT_OR_SATURATION_CONFIG_INVALID
- `805` INTERNAL_ERROR
- `806` UNKNOWN
- `807..80F` reserved

N·m/LSBは`TODO(SIMULATION)`。actual actuator saturationはfieldを上書きせずFlight Status bit12でも示す。

Control entry前または`control_roll_reference_valid=false`ではRoll Controller自体を実行しない。したがってreference未captureを0 radと仮定したnumeric requested torqueは送信せず、Control未実行として`UNAVAILABLE`を使用する。LQR入力の`roll_deviation_unwrapped_rad`と表示用`corrective_roll_error_unwrapped_rad`は符号が逆の別semanticとする。

## 12. Flight elapsed

8 bit、0.1 s/LSB。`0x00..0xEF`=0.0..23.9 s。`0xF0..0xFF`は共通時刻error codeを使用する。

## 13. GNSS

LoRa compact telemetryの水平位置は固定ランチャー座標を原点とする局所East/Northで表現する。

- reference latitude: **40.242865 deg**
- reference longitude: **140.010450 deg**
- `north_m = round((latitude_deg - 40.242865) * 111039.303376)`
- `east_m = round((longitude_deg - 140.010450) * 85090.557487)`

East/Northはsigned16、1 m/LSB。`0x8000..0x800F`をerror領域とし、正常countは-32752..32767を使用する。

- `8000` UNAVAILABLE
- `8001` NO_FIX
- `8002` STALE
- `8003` OUT_OF_RANGE
- `8004` INVALID_SAMPLE
- `8005` RECEIVER_ERROR
- `8006` REFERENCE_INVALID
- `8007` INTERNAL_ERROR
- `8008` UNKNOWN
- `8009..800F` reserved

heightは9 bit absolute height。raw0..495を正常値とし、`height_m = -100 + raw*5`で-100..2375 m。

- 496 UNAVAILABLE
- 497 NO_FIX
- 498 STALE
- 499 OUT_OF_RANGE
- 500 INVALID_SAMPLE
- 501 RECEIVER_ERROR
- 502 INTERNAL_ERROR
- 503 UNKNOWN
- 504..511 reserved

## 14. Descent Status 13 bit

- bit0 LPSによる開傘条件成立
- bit1 elapsedによる開傘条件成立
- bit2..3 parachute state
- bit4 `DeploymentPowerCutoffDone`
- bit5 通信基板microSD healthy
- bit6 Mission↔通信基板CAN healthy
- bit7 `DeploymentShockConfirmed`
- bit8 STS3215 overload
- bit9 STS3215 overcurrent
- bit10 STS3215 overtemperature
- bit11 STS3215 encoder fault
- bit12 STS3215 voltage fault

`DeploymentPowerCutoffDone`はパラシュートサーボおよび差圧系基板の両方の電源遮断完了を意味する。

parachute state:

- `00` Holding / Open未開始
- `01` OpeningOrRetrying
- `10` OpenConfirmed
- `11` OpenFailed

## 15. parachute angle

本fieldはSTS3215を`OperatingMode::position` + `FeedbackMode::multi_turn`で取得したfresh physical current positionを、1回転内へwrapした絶対角である。Step modeの相対残量、targetまでの残差、commanded displacementを送ってはならない。

8 bit、1.5 deg/LSB。raw0..240=0..360 deg。

- 241 NOT_INITIALIZED
- 242 UART_TIMEOUT
- 243 UART_PROTOCOL_ERROR
- 244 DEVICE_ERROR_RESPONSE
- 245 CONFIGURATION_INVALID
- 246 WRONG_OPERATING_MODE
- 247 STALE
- 248 POSITION_OUT_OF_RANGE
- 249 POWERED_OFF
- 250 OPEN_COMMAND_FAILED
- 251 RETRY_EXHAUSTED
- 252 POSITION_INVALID
- 253 INTERNAL_ERROR
- 254 UNKNOWN
- 255 UNAVAILABLE

STS自身の5 faultはDescent Status bitへ出す。

## 16. Descent elapsed

16 bit、0.1 s/LSB。`0x0000..0xFFEF`=0..6551.9 s。`0xFFF0..0xFFFF`は共通時刻error code。

## 17. Recovery battery / elapsed

Battery1=logic、Battery2=motor。

battery voltageは8 bit、0.05 V/LSB。raw0..240=0.00..12.00 V。

- 241..252 reserved
- 253 STALE
- 254 ADC_ERROR
- 255 UNAVAILABLE

Recovery elapsedは16 bit、10 s/LSB。`0x0000..0xFFEF`正常、`0xFFF0..0xFFFF`共通時刻error code。

## 19. Golden vector

Mission C++、通信基板Rust、地上局は本書の同じ量子化規則と[[04_通信仕様|通信仕様]]のLSB-first packing規則を使用する。

少なくとも正常値、負値、各reserved/error領域、境界値、checksumを含むgolden vectorを共有し、codec変更時に3実装すべてで一致を確認する。
